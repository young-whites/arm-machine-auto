# 上位机-机械臂 Modbus 通信协议流程文档

> 基于 `openclaw_main.c` 实现的上位机控制流程，逐阶段描述指令交互细节。

---

## 1. 通信架构

```
┌──────────────┐                          ┌──────────────┐
│   上位机      │                          │   机械臂      │
│  (STM32)     │                          │  (Robot Arm) │
│              │                          │              │
│  FC06 写 AI  │ ── AI 寄存器(100~104) ──→ │ WaitAI/ReadAI│
│              │                          │              │
│  FC03 读 AO  │ ←── AO 寄存器(100~101) ── │ WriteAO(FC16)│
└──────────────┘                          └──────────────┘
```

| 方向 | 寄存器 | 地址 | 功能码 | 写方 | 读方 | 用途 |
|------|--------|------|--------|------|------|------|
| 上位机→机械臂 | AI0 | 100 | FC06 写 | 上位机 | 机械臂 WaitAI | 启动信号 |
| 上位机→机械臂 | AI1 | 101 | FC06 写 | 上位机 | 机械臂 WaitAI/ReadAI | 药瓶编号 / 动作完成确认 |
| 上位机→机械臂 | AI3 | 103 | FC06 写 | 上位机 | 机械臂 ReadAI | 取药数量 |
| 上位机→机械臂 | AI4 | 104 | FC06 写 | 上位机 | 机械臂 ReadAI | 取药口位 |
| 机械臂→上位机 | AO0 | 100 | FC03 读 | 机械臂 FC16 写 | 上位机 FC03 轮询 | 总程序完成标记 |
| 机械臂→上位机 | AO1 | 101 | FC03 读 | 机械臂 FC16 写 | 上位机 FC03 轮询 | 步骤状态/到位信号 |

### 核心规则

- **上位机是主站**，必须主动轮询 AO 寄存器获取机械臂状态
- **机械臂不主动上传**，只在到达关键位置时写 AO 寄存器
- 机械臂写完 AO 后**立即清零**，上位机必须在清零前捕获到信号
- 上位机完成操作后写 AI1=1 确认，随后清零 AI1=0
- 每一次信号交换都是一次**握手**：AO 信号 → 上位机执行 → AI 确认 → 清零

### 超时处理

| 参数 | 值 | 含义 |
|------|-----|------|
| `MODBUS_POLL_INTERVAL_MS` | 100ms | AO 轮询间隔 |
| `STEP_TIMEOUT_MS` | 10000ms | 单次轮询超时 |
| `MAX_RETRY_COUNT` | 3 | 超时重试次数 |

**超时行为：**
- 单次轮询超时（10秒未检测到 AO 信号）→ 打印错误日志，重试
- 重试耗尽（总计 30 秒）→ 当前阶段失败 → 停止系统 → 重置所有寄存器
- 通信错误（FC03/FC06 发送失败或响应异常）→ 打印错误，短暂延迟后重试

## 2. 逐阶段通信流程

### 阶段1：启动

**目的：** 上位机通知机械臂开始工作循环。

**上位机操作：**
1. FC06 写 AI0(100)=1（启动信号）
2. 延迟 50ms 确保机械臂读取
3. FC06 写 AI0(100)=0（清零）

**机械臂行为：**
- Lua 脚本中 `ModbusSlaveWaitAI(AI0, 0, 0, -1)` 等待 AI0>0
- 检测到 AI0=1 后，进入阶段2（取药瓶）

**无响应处理：**
- 机械臂在总程序入口等待 AI0>0，**无限等待**，不会超时
- 如果上位机不发送启动信号，机械臂永远停在这里
- 上位机此阶段不需要等待响应，写入即完成

**时序：**
```
上位机                              机械臂
─────────────────────────────────────────────
  FC06 AI0=1 ──────────────────→ WaitAI(AI0>0) 检测到
  FC06 AI0=0 ──────────────────→ (清除)
                                   进入阶段2
```

---

### 阶段2：取药瓶

**目的：** 上位机告诉机械臂取哪个瓶子（1~8号）。

**上位机操作：**
1. FC06 写 AI1(101)=药瓶编号（1~8）
2. 延迟 50ms 后清零
3. 轮询 AO1，等待机械臂信号

**机械臂行为：**
- `ModbusSlaveWaitAI(AI1, 0, 0, -1)` 等待编号
- `ModbusSlaveReadAI(AI1, 1)` 读取编号
- 执行取瓶动作

**反瓶流程（如果瓶子是反向放置的）：**

机械臂需要上位机配合两次操作：

| 步骤 | 机械臂动作 | 上位机动作 |
|------|-----------|-----------|
| 1 | 写 AO1=1（通知需要夹紧盖子） | 轮询检测到 AO1=1 → 执行夹紧 → 写 AI1=1 确认 → 清零 |
| 2 | 写 AO1=1（通知需要换位） | 轮询检测到 AO1=1 → 执行换位 → 写 AI1=1 确认 → 清零 |

正瓶流程：机械臂不写 AO1，上位机轮询超时后认为是正瓶，直接继续。

**无响应处理：**
- 上位机轮询 AO1 超时（10秒）→ 认为正瓶流程，跳过反瓶步骤，继续阶段3
- 反瓶流程中上位机夹紧/换位失败 → 停止系统

**时序（反瓶）：**
```
上位机                              机械臂
─────────────────────────────────────────────
  FC06 AI1=瓶号 ──────────────→ WaitAI(AI1>0), 读取编号
  FC06 AI1=0     ──────────────→ (清除)
                                   取瓶动作...
                                   WriteAO(AO1=1) → 夹紧信号
  FC03 轮询检测 AO1=1 ←────────
  (执行夹紧操作)
  FC06 AI1=1 ─────────────────→ WaitAI(AI1>0) 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                   WriteAO(AO1=1) → 换位信号
  FC03 轮询检测 AO1=1 ←────────
  (执行换位操作)
  FC06 AI1=1 ─────────────────→ WaitAI(AI1>0) 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                   继续下一阶段
```

---

### 阶段3：拧松瓶盖

**目的：** 机械臂就位后，请求上位机执行拧松瓶盖操作。

**机械臂操作：**
1. 执行取瓶到位动作
2. 写 AO1=2（拧松请求信号）
3. 清零 AO1=0
4. 等待上位机确认（WaitAI(AI1>0)）

**上位机操作：**
1. FC03 轮询检测 AO1 非零值
2. 检测到信号 → 执行拧松动作（控制拧松机）
3. FC06 写 AI1=1 确认拧松完成
4. 清零 AI1=0

**无响应处理：**
- 上位机轮询 AO1 超时（10秒×3次 = 30秒）→ 停止系统
- 上位机拧松机执行失败 → 停止系统（不写 AI1 确认，机械臂一直等待）
- 机械臂 WaitAI 无限等待，直到上位机写 AI1=1

**时序：**
```
上位机                              机械臂
─────────────────────────────────────────────
                                   WriteAO(AO1=2) → 拧松请求
                                   WriteAO(AO1=0) → 清除
                                   WaitAI(AI1>0)
  FC03 检测到 AO1=2 ←────────
  (执行拧松操作)
  FC06 AI1=1 ─────────────────→ WaitAI 检测到, 拧松完成
  FC06 AI1=0 ─────────────────→ (清除)
                                   继续阶段4
```

---

### 阶段4：取药

**目的：** 机械臂移动到各个取药口，上位机在每个口位执行取药操作。

**准备阶段：**

| 步骤 | 机械臂 | 上位机 |
|------|--------|--------|
| 1 | 写 AO1=1（就绪信号） | FC03 轮询检测到 AO1=1 |
| | WaitAI(AI3>0) | FC06 写 AI3(103)=取药数量 |
| | WaitAI(AI4>0) | FC06 写 AI4(104)=第一个口位 |
| | ReadAI(AI3) → 数量 | 清零 AI3=0 |
| | ReadAI(AI4) → 口位 | 清零 AI4=0 |

**循环取药（N 次）：**

| 步骤 | 机械臂 | 上位机 |
|------|--------|--------|
| 1 | 移动到目标口位 | — |
| 2 | 写 AO1=1（到达信号） | FC03 轮询检测到 AO1=1 |
| 3 | WaitAI(AI1>0) | 执行取药操作 |
| 4 | — | FC06 写 AI1=1 确认 |
| 5 | WaitAI 检测到, 继续下一口位 | FC06 写 AI1=0 清零 |

**无响应处理：**
- 上位机轮询 AO1 超时 → 停止系统
- 上位机取药操作失败 → 不写 AI1 确认 → 机械臂 WaitAI 超时 → 机械臂停止
- 任何单口位失败 → 整个流程停止

**时序：**
```
上位机                              机械臂
─────────────────────────────────────────────
                                   WriteAO(AO1=1) → 就绪
  FC03 检测到 ←──────────────
  FC06 AI3=数量 ──────────────→ ReadAI(AI3)
  FC06 AI4=口位 ──────────────→ ReadAI(AI4)
  FC06 AI3=0, AI4=0
                                   for N 次:
                                     移动到口位
                                     WriteAO(AO1=1) → 到位
  FC03 检测到 ←──────────────
  (执行取药)
  FC06 AI1=1 ─────────────────→ WaitAI 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                     继续下一口位
```

---

### 阶段5：拧紧瓶盖

**目的：** 取药完成后，机械臂放回瓶子，上位机执行拧紧瓶盖操作。

**两次信号交换：**

| 次数 | 机械臂 AO1=1 含义 | 上位机操作 |
|------|-------------------|-----------|
| 第1次 | 到位，可以闭合夹爪并拧紧 | 闭合夹爪 → 拧紧瓶盖 → 写 AI1=1 确认 → 清零 |
| 第2次 | 拧紧完成，松开夹爪 | 松开夹爪 → 写 AI1=1 确认 → 清零 |

**无响应处理：**
- 轮询 AO1 超时 → 停止系统
- 拧紧操作失败 → 不确认 → 机械臂等待超时 → 停止

**时序：**
```
上位机                              机械臂
─────────────────────────────────────────────
                                   WriteAO(AO1=1) → 到位
  FC03 检测到 ←──────────────
  (闭合夹爪, 拧紧)
  FC06 AI1=1 ─────────────────→ WaitAI 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                   (机械臂配合拧紧)
                                   WriteAO(AO1=1) → 完成
  FC03 检测到 ←──────────────
  (松开夹爪)
  FC06 AI1=1 ─────────────────→ WaitAI 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                   继续阶段6
```

---

### 阶段6：摇匀出药

**目的：** 将药瓶放入摇匀机，执行摇匀，然后取出放到出药口。

**三次信号交换：**

| 次数 | 机械臂 AO1=1 含义 | 上位机操作 |
|------|-------------------|-----------|
| 第1次 | 药瓶已放入机器夹爪位 | 上位机夹爪闭合夹住药瓶 → 写 AI1=1 → 清零 |
| 第2次 | 机械臂已退回，可以摇匀 | 上位机执行摇匀动作 → 写 AI1=1 → 清零 |
| 第3次 | 机械臂重新抓取药瓶 | 上位机松开夹爪 → 写 AI1=1 → 清零 |

**无响应处理：**
- 任何一次轮询 AO1 超时 → 停止系统
- 摇匀操作异常 → 不确认 → 机械臂等待超时 → 停止

**时序：**
```
上位机                              机械臂
─────────────────────────────────────────────
                                   WriteAO(AO1=1) → 放瓶到位
  FC03 检测到 ←──────────────
  (夹爪闭合夹住药瓶)
  FC06 AI1=1 ─────────────────→ WaitAI 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                   (机械臂松开, 退回)
                                   WriteAO(AO1=1) → 可以摇匀
  FC03 检测到 ←──────────────
  (执行摇匀动作)
  FC06 AI1=1 ─────────────────→ WaitAI 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                   (机械臂回去抓取)
                                   WriteAO(AO1=1) → 抓取完成
  FC03 检测到 ←──────────────
  (松开夹爪)
  FC06 AI1=1 ─────────────────→ WaitAI 检测到
  FC06 AI1=0 ─────────────────→ (清除)
                                   (机械臂取出 → 出药口放下)
```

---

### 阶段7：总程序完成

**目的：** 机械臂通知上位机整个流程完成。

**机械臂操作：**
- 写 AO0(100)=2（总程序完成标记）
- 清零 AO0=0
- 回到阶段1，等待下一轮启动

**上位机操作：**
1. FC03 轮询 AO0，等待值=2
2. 检测到完成 → 打印周期统计 → 回到阶段1（循环模式）或停止（单次模式）

**无响应处理：**
- AO0 轮询超时（30秒×3次 = 90秒）→ 停止系统
- 单次模式下完成 → 自动停止
- 循环模式下完成 → 延迟1秒 → 回到阶段1

## 3. 指令速查表

### 上位机发送（FC06 写 AI）

| 指令 | 寄存器 | 值 | 用途 | 期望机械臂响应 |
|------|--------|-----|------|---------------|
| 写 AI0=1 | 100 | 1 | 启动系统 | 机械臂开始执行阶段1 |
| 写 AI0=0 | 100 | 0 | 清零启动信号 | — |
| 写 AI1=瓶号 | 101 | 1~8 | 指定取哪个瓶子 | 机械臂执行取瓶 |
| 写 AI1=1 | 101 | 1 | 确认动作完成 | 机械臂继续下一步 |
| 写 AI1=0 | 101 | 0 | 清零确认信号 | — |
| 写 AI3=数量 | 103 | 1~20 | 告诉取药份数 | 机械臂读取后开始取药循环 |
| 写 AI4=口位 | 104 | 1~20 | 告诉第一个取药口位置 | 机械臂读取后移动 |

### 上位机轮询（FC03 读 AO）

| 轮询目标 | 寄存器 | 期望值 | 含义 | 检测到后执行 |
|----------|--------|--------|------|------------|
| AO1 | 101 | >0 | 机械臂有信号 | 根据阶段上下文执行对应操作 |
| AO0 | 100 | 2 | 总程序完成 | 统计完成，进入下一循环或停止 |

### 机械臂发送（FC16 写 AO）

| 寄存器 | 值 | 含义 | 期望上位机操作 |
|--------|-----|------|---------------|
| AO1 | 1 | 到位/就绪 | 执行对应阶段操作后写 AI1=1 |
| AO1 | 2 | 请求拧松（阶段3专用） | 执行拧松后写 AI1=1 |
| AO1 | 0 | 清除信号 | —（中间状态） |
| AO0 | 2 | 总程序完成 | 上位机统计并进入下一轮 |

## 4. 异常处理汇总

| 异常场景 | 检测方 | 处理方式 |
|----------|--------|---------|
| AO 轮询超时（10秒） | 上位机 | 重试（最多3次），耗尽后停止系统 |
| FC03 读取失败 | 上位机 | 打印错误，等待轮询间隔后重试 |
| FC06 写入失败 | 上位机 | 打印错误，停止当前阶段 |
| 上位机操作异常（拧松/取药等） | 上位机 | 不写 AI1 确认 → 机械臂 WaitAI 超时 → 停止 |
| 机械臂 WaitAI 超时 | 机械臂 | 机械臂停止，上位机检测不到 AO 信号 → 上位机超时 → 停止 |
| 收到 `stop` 命令 | 上位机 | 设置 `g_stop_requested=1` → 各阶段检测后退出 → 重置寄存器 |
| 收到 `reset` 命令 | 上位机 | 停止系统 → 清零所有 AI 寄存器 |
| 单次模式完成 | 上位机 | 自动停止，等待下一次 `start` 命令 |
| 循环模式完成 | 上位机 | 延迟1秒 → 自动开始下一轮 |

## 5. 关键代码函数对应

| 函数 | 功能 | 对应协议操作 |
|------|------|------------|
| `stage_startup()` | 发送启动信号 | FC06 写 AI0=1 → 清零 |
| `stage_pick_bottle()` | 发送药瓶编号 + 处理反瓶 | FC06 写 AI1=瓶号 → FC03 轮询 AO1 → FC06 写 AI1 确认 |
| `stage_loosen_cap()` | 检测拧松请求 → 执行 | FC03 轮询 AO1 → 拧松 → FC06 写 AI1 确认 |
| `stage_dispense()` | 发送取药参数 + 循环取药 | FC06 写 AI3/AI4 → FC03 循环检测 → FC06 写 AI1 确认 |
| `stage_tighten_cap()` | 两次信号交换拧紧 | FC03 轮询 → 拧紧/松开 → FC06 写 AI1 确认 |
| `stage_shake_dispense()` | 三次信号交换摇匀 | FC03 轮询 → 夹爪/摇匀/松开 → FC06 写 AI1 确认 |
| `stage_complete()` | 检测完成标记 | FC03 轮询 AO0=2 |
| `wait_robot_signal()` | 轮询 AO1 非零值 | FC03 循环读取 AO1 |
| `ack_robot()` | 确认并清零 | FC06 写 AI1=1 → 延迟 → FC06 写 AI1=0 |
| `openclaw_reset_all()` | 重置所有寄存器 | FC06 写 AI0~AI4=0 |
